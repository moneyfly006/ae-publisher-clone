# Alibaba 刊登评分（发布门禁）说明

> 代码：`src/aeclone/services/alibaba_score.py`；测试：`tests/test_alibaba_score.py`
> 门禁：`op=2` 提交审核/发布要求 **评分 ≥ 4.5 / 5**，否则阻止提交并列出缺失项。

## 1. 为什么要评分

`op=1` 保存成功只说明格式被接受，**不代表审核能过**。评分把「平台审核最常卡的点」
做成本地可解释的检查，发布前先拦截，减少「提交→审核失败→再改」的循环。

## 2. 维度与权重（0~5 分，加权合计 100）

| 维度 | 权重 | 检查内容 | 典型修复 |
|---|---|---|---|
| 类目与属性 | 20 | 末级类目、必填属性齐全、**占位值**（Other/All 等） | 读必填、属性预设、AI 建议 |
| 标题 | 15 | 30~128 字符、纯 ASCII、无违禁/促销/联系方式、信息词数量 | AI 标题或手改 |
| 关键词 | 10 | 3~5 个英文关键词、与标题重叠 | AI 关键词/手填 |
| 详情描述 | 20 | 纯文本 800~1800 字符（平台上限 2000）、≥3 张详情图、无 HTML/联系方式/违禁词 | AI 详情（纯文本）、清理 |
| 图片 | 15 | 主图 4~6 张；可选真实尺寸检查（≥800/1000） | 补主图/换大图 |
| 商品视频 | 5 | `mainVideoId/detailVideoId` 是否存在 | 平台侧上传视频 |
| 价格与贸易 | 10 | 价格模型、阶梯/FOB、MOQ、包装尺寸、重量、**物流属性**、**发货期**、HS、库存 | 价格与贸易页补齐 |
| 合规 | 5 | 违禁/绝对化词、联系方式、占位属性 | 删除/替换 |

规则要点：
- **合规词按词边界匹配**：`cure` 不再误伤 `securely/moisture`。
- 占位值检测排除合法值属性（High-concerned chemical=None 等）。
- 详情默认按**纯文本**评估（平台 textDesc 不收 HTML）；含 HTML 会扣分并提示。
- 图片尺寸检查用 `probe_image()`（真实下载头部读尺寸）；离线测试可注入 `image_checker`。
- 硬阻断（与分数无关）：无类目、无标题、无主图、必填属性缺失、详情过短。

## 3. 真实商品示例（220114598434958580，泳池）

修复前（含占位属性、HTML 详情、缺 HS/发货期/物流属性）：

```
评分 4.12/4.5 · 未通过
  ✗ 类目与属性: 3.6  — 占位属性 high-concerned chemical / applicable people
  ✗ 商品视频: 1.0    — 无视频（保存接口无视频字段）
  ✗ 合规: 2.9        — "cure" 误报（已修复为词边界）
  ✗ 价格与贸易: 4.0  — HS 为空
```

修复后（属性覆盖 Applicable People=All、HS=9506999000、发货期/物流属性写入）：

```
评分 4.80/4.5 · 通过
  ✓ 类目与属性 5.0  ✓ 标题 5.0  ✓ 关键词 5.0  ✓ 详情 5.0
  ✓ 图片 5.0        ✗ 视频 1.0（单列提醒）  ✓ 价格与贸易 5.0  ✓ 合规 5.0
```

> 视频缺失只扣该维度（权重 5），其他维度满分时仍可 ≥4.5；视频需平台侧上传。

## 4. UI 与门禁行为

- 页面 12「预演 / 保存」新增 **刊登评分与发布门禁** 卡：按钮「评分并诊断」→ 总分 +
  每个维度进度条 + 问题/修复建议。
- 保存动作选 `op=2` 时：
  1. UI 先跑一次 `dry_run op=2` 预检（评分、经营类目范围）；不达标直接阻断并展示缺什么；
  2. 确认弹窗展示「刊登评分」与「类目经营范围预检」；
  3. pipeline 在真正保存前再次强制校验（CLI/其它入口同样生效）。
- `op=1/3` 不受发布线限制（保存草稿允许低分，但会显示评分与建议）。
