```

════════════════════════════════════════════════════════════════════

   ├─ 3. 价格 / 价格与物流 / 价格与贸易
   └─ 4. 变种与库存 / SKU 与库存

   ├─ 6. AI 图片 / 图片与视频

   ├─ 10. 图片工作台
```
