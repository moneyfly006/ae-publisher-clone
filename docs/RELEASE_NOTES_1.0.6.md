# AuroraList v1.0.6 发行说明（2026-11-22）

## 新增
- **Alibaba 刊登评分（发布门禁）**：8 维度评分，`op=2` 必须 ≥4.5，不达标逐项指出
  「缺什么/去哪里补」。
- **经营类目范围预检**：发布前用在线商品类目样本近似判断能否发；失败时明确提示
  客户去「卖家中心 → 店铺管理 → 管理公司信息 → 经营类目」开类目。
- **发布失败列表**：Alibaba 发布队列显示「发布失败」数量与原因（平台 errMsg），支持打开商品重发。
- 图片工作台/日志等共享页 Alibaba 专属裁剪（详见 PLATFORM_UI_MATCH.md）。

## 修复（真实发布踩坑）
- `textDesc` 改为纯文本且 ≤2000 字符（HTML 会被平台拒绝）。
- 发布必填 `deliver_periods`、`logisticsProperty`/重量/尺寸全填或全清。
- 外层 `code=0` 但内层业务失败不再误报成功。
- 审核中（`PRODUCT_BIZCHECK...IN_AUDITING`）判为已提交、幂等。
- 主视频复用 >20 个（`CHK_VIDEO_PRODUCT_LINK_LIMIT`）翻译为可执行中文提示。
- 发布后回读状态，异步「发布失败」不再显示成功。

## 正式版清理
- 版本号 v1.0.6；测试期措辞改为正式措辞；按钮/选项全量审计 0 error。

## 待客户操作
- 泳池类目需在卖家中心开通经营类目；主视频复用超限的商品需更换/删除主视频。
## 追加验证（op=3 / op=5）
- op=3 真实生效：采集箱商品 → 待发布（`waitPublish`）。
- op=5 真实生效：采集箱商品 → 定时发布（`publishingTiming`）；
  `dxmScheduleTime`（13 位毫秒）已验证，UI 保存动作新增 op=5 + 「定时发布时间」。

## 本次 1.0.6 追加（2026-11-23）
- 旧设备授权客户迁移期临时开通全部平台；
- 运行一段时间后邮箱+密码绑定账号，自动绑定机器码并同步后台；
- 绑定后下次启动账号登录；支持保存密码自动登录；
- 后台新增 `api.php?action=software_bind` 迁移绑定接口；
- 账号密码同时可用于授权网站登录（同一 users 表）；
- SKU 元数据/重复组合清洗、旧机器码兼容、机器码多硬件标识。
