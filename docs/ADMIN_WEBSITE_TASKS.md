# 网站管理员后台逐项改造任务

范围：仅网站 `/admin` 及其服务端、现有软件上报接口的接收与分析。此轮不修改软件界面或客户端代码，不改变用户端购买流程。原设备授权码、状态、到期和原验证接口保留，除用户后续明确要求删除的退款管理、发票功能外，其余管理功能保留入口。

每项完成条件：代码落地 → 对应测试/页面操作 → 记录结果 → 勾选。生产部署前完成隔离验收与备份，部署后重新核对原授权数据。
