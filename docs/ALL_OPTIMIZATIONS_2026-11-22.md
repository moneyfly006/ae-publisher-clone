# 四平台全部优化实施与验收

本轮实现上一轮建议的八项优化，覆盖 Alibaba、Amazon、TikTok、Shopee。速卖通导航、页面、配置和发布流程保持原样；其相关测试随全量回归执行。

## 功能与操作位置

| 优化 | 当前行为 |
|---|---|
| 任务持久化与恢复 | 每件商品记录 queued / preparing / prepared / submitting / done 阶段、应用字段和结果。本地 SQLite 开启 WAL；任务记录不包含 Cookie 或 API Key。发布页的历史任务可查看未完成任务并继续。 |
| 可靠恢复 | 已完成项不重新执行；提交时中断的商品先回读状态并跳过重发。只看到草稿不足以证明上次修改已成功，仍标记结果待确认。相同店铺/站点的任务有跨窗口文件锁，进程退出后自动释放。失败修复也使用任务记录。 |
| 结果状态 | 区分检查通过、草稿已保存、待发布、平台处理中、审核中、发布成功、需补资料、结果待确认。不会以草稿保存代替线上发布成功。审核通知与真实错误并存时优先显示需要处理的错误。 |
| 参数显示 | 运行卡显示当前实际值，非标准组合显示“自定义”；选择预设可先看说明再应用。历史任务可展开原参数快照。恢复任务沿用原商品规则及发布去向，确认后可使用当前页面的 AI 次数/金额上限，已消耗部分不清零。 |
| 可视化表单 | Alibaba / Amazon 属性支持名称和值编辑；TikTok / Shopee 从平台候选中选择原生属性 ID / 值 ID。Alibaba 阶梯价、包装重量尺寸、交期和仓库库存改为可增删表单；高级 JSON 保留并与可视化编辑同步。保留未展示的原生字段。 |
| 结果查询 | 发布页提供历史任务、搜索、状态筛选、每页20条、CSV导出、平台状态回读及修正设置跳转。可一键滚动到任务结果。此列表仅展示任务结果，不参与采集箱手工选品。 |
| 店铺与站点预设 | 规则按平台、店铺、站点及商品类型隔离。首次升级保留当前规则；切换到新范围使用默认值，切回原范围恢复原规则。提示词、价格等批量规则不再串用；读取到已属于另一店铺的商品时阻止套用当前店铺预设。功能页显示预设适用范围。 |
| 页面与读取性能 | 默认自动设置页不构建旧单品工作台；点击单品高级编辑后才创建并在本页复用。参考属性/限额等按本次运行缓存，准备阶段的商品详情复用；进入提交阶段清空详情缓存并强制重新读取。 |
| AI预算与复用 | 自动任务默认最多100次AI操作，金额上限可选；按所填单次预算价预估并在调用前预约。相同店铺、商品事实、模型、提示词的成功结果可持久化复用30天，支持文案、SKU、属性及转存后的图片URL。事实或规则变化会重新生成；状态/历史错误变化不单独使缓存失效。 |

## AI与提交的关键约束

- “次数上限”约束自动任务中的生成操作。自动图片内部的付费重试已关闭，不改变用户手工图片处理或速卖通原有重试设置。
- AI请求失败或中断后，该次预约仍保留；同一任务中结果未知的请求不会自动重发。生成成功但商品保存失败，后续可复用已保存的结果。
- 预算达到上限时暂停剩余商品，当前未提交商品保留为未完成。调整上限后继续任务，已有计数不重置。
- 未填写模型预算单价时，金额显示未知，不能解释为免费。设置金额上限后，启用的对应模型必须填写预算单价。金额按此单价预约，并非服务商实际账单或对实际费用的保证；实际调用费用以服务商计费为准。
- 网络异常不自动重发保存/发布。结果待确认可只读回查；经营类目、识别码、型录、变种主题等真实资料不能由AI猜填。
- 新版没有删除旧的隐藏综合编辑兼容路由。普通自动设置页已按需加载；首次进入单品高级编辑时仍会创建兼容编辑器。
