# AuroraList v1.0.9 发行说明（2026-11-23）

## 旧授权客户迁移
- 旧设备授权客户升级后**临时开通全部平台**（Alibaba/速卖通/Amazon/TikTok/Shopee），先正常使用；
- 运行一段时间后弹窗引导绑定账号：只需邮箱 + 密码；
- 绑定自动完成：
  - 没有账号则自动创建；
  - 机器码绑定到账号；
  - 同步到授权后台（lc_devices / lc_links）；
  - 后台临时下发全部平台权限；
- 绑定完成标记 `license_account_bound`；下次启动要求账号登录；
- 勾选“保存密码”后，密码使用本机密钥加密保存，下次启动自动登录；
- 未勾选保存密码，则下次启动必须输入账号密码；
- 绑定/登录后全部平台功能可用。

## 兼容
- 旧授权码仍有效，旧机器码继续作为兼容候选；
- 后台新增 `/api.php?action=software_bind` 迁移绑定接口；
- 既有授权、订单、签名密钥不改。

## 验证
- `tests/test_account_migration.py`：全平台、绑定弹窗、保存密码加密、自动登录；
- 离线全量 1268 测试通过。
