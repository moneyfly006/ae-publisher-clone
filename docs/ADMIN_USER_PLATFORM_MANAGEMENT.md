# 后台：套餐用户编辑、平台绑定与设备上限

## 入口
- `/admin/shop-users` → 每行「管理 / 编辑」「平台绑定」
- 用户详情：
  - 账号资料 / 重置密码
  - 当前有效权限
  - 平台绑定与添加/删除
  - 账号设备与绑定上限

## 平台权限
- 添加平台：选择平台 → 30 天（或“添加/延长”选择天数）
- 删除平台：只移除该平台，其他平台和历史记录保留
- 每个平台、功能分别计算到期
- 历史开通记录仍保留，可单独取消

## 设备数上限
优先级：
1. 账号单独设置（用户详情 → 账号设备与绑定上限，0=跟随）
2. 套餐的“允许设备数”
3. 系统设置 → 授权默认值 → 账号默认可绑定设备数

降低上限不会强制解绑已有设备；下次绑定设备时按新上限检查。
