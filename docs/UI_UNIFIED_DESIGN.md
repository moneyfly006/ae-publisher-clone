# 多平台统一 UI 设计方案

> **设计原则**: 以速卖通（AliExpress）的页面结构为标准，所有平台按相同的功能顺序组织

**设计日期**: 2026-11-24  
**设计版本**: v2.0  
**参考标准**: 速卖通 AliExpress 现有结构

---

- ✅ 总共 12 个页面（无隐藏页面）

- ✅ 页面顺序符合用户操作流程
- ✅ 命名简洁明确
