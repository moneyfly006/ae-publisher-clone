# 旧授权客户迁移到账号体系（v1.0.9）

## 客户升级后
1. 旧设备授权码继续有效；客户端会兼容新/旧机器码。
2. 迁移期临时开通全部平台：Alibaba、速卖通、Amazon、TikTok、Shopee。
3. 启动不会强制登录，客户可以先正常使用。

## 运行一段时间后
- 默认启动 10 分钟后弹窗「绑定授权账号」；
- 客户只需填写：
  - 邮箱（已有账号则填原邮箱；没有则自动创建）；
  - 密码；
  - 可勾选「保存密码」。
- 点击「绑定并继续」后客户端调用后台 `api.php?action=software_bind`：
  - 创建/验证账号；
  - 绑定当前机器码到账号；
  - 临时授予全部平台权限；
  - 写入后台设备与旧授权关联。

## 绑定完成后
- 下次启动必须账号登录；
- 如果勾选了「保存密码」：密码使用本机密钥加密保存，自动登录；
- 未勾选：每次启动输入邮箱和密码；
- 登录成功后全部平台功能可用。

## 后台接口
`POST /api.php?action=software_bind`

```json
{"email":"user@example.com","password":"******",
 "machine_code":"XXXXXXXX-XXXXXXXX",
 "legacy_identities":["旧授权ID","旧机器码"]}
```

成功返回账号绑定的平台 token；后台保留旧授权记录，不删除、不改写。
