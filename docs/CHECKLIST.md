## 九、每项完成后的验证步骤（通用）

1. **单元级**：`py_compile` + 目标函数真实参数跑一次，打印输入/输出
2. **界面级**：`tools/button_audit.py` 全回调 0 error + 页面截图
3. **链路级**：真实调用一次（核对站点日志 model 名、扣费、耗时）
4. **回归**：受影响的其他功能都跑（改模型后：白底/去水印/审查/发布）
5. **打包**：`pyinstaller app.spec` → 启动 → 关键页面点一遍
6. **记录**：更新本清单 + commit 写验收结论
