# 授权网站用户端与管理员后台审查

审查日期：2026-11-22。范围：[授权与边界](license-review-scope.md)。本轮为检查和建议，未部署生产修复。

## 结论

后台「套餐用户 → 管理 → 手动开通」写入用户端读取的同一个授权库，用户刷新页面后能看到平台和到期日期。已正常登录既有 demo 账号，并在概览和「我的授权」看到五个平台及到期日期。

但当前不能保证多次开通后的权限完整：用户端及软件登录只取最新一条未吊销记录，单独开通第二个平台会隐藏先前平台。旧「授权管理」是另一套机器码授权，不会自动关联账号用户端。「我的授权」还有实际 JavaScript 异常，平台摘要出现后，Token 加载代码被中断。

更需优先处理的是公开目录中的数据库及备份可被未登录请求访问，以及支付、续费和设备解绑的一致性问题。这些结论分别来自线上只读检查、浏览器操作和隔离测试，不代表已执行真实支付、真实授权变更或退款。

## 验收标准

后台操作完成后，成功提示应明确「哪个账号、哪个平台、哪些功能、从何时到何时、关联哪些设备」，并提供查看用户有效权益的入口。用户刷新或重新进入授权页后应显示同一份计算结果；软件刷新后应拿到相同权益。分别购买不同平台不能丢失旧平台，续费不能延长未购买的其他平台，重试支付不能重复发放或扣款，吊销与断网必须返回不同状态。
