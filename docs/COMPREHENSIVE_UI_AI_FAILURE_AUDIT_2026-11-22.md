## 已实现的自动化入口

| 功能 | Alibaba | Amazon | TikTok | Shopee |
|---|---|---|---|---|
| AI文案 | 标题、详情、关键词 | 标题、完整五点、描述、搜索词 | 标题、描述；US支持五点和搜索词 | 标题、描述；兼容新版描述字段 |
| 处理方式 | 补齐缺失 / 重写所选字段 | 同左 | 同左，自动遵守站点字段范围 | 同左 |
| 文案预设 | 通用保真、专业参数、使用场景、精简合规、自然搜索词 | 同左 | 同左 | 同左 |
| AI图片 | 指定序号编辑、白底、棚拍、翻译、去叠加水印；转存后回填 | 同左 | 同左 | 同左 |
| AI编码 | 仅补已有变种缺失编码 | 仅补缺失父SKU | 保留已有变种编码 | 仅补缺失父SKU |
| AI属性建议 | 原文证据 + 类目候选 | 原文证据 + 类目字段 | 原文证据 + 原生属性ID | 原文证据 + 原生属性ID |

文案由一个总开关控制，可选择实际需要处理的字段。Amazon 五点始终使用一次调用、一个提示词生成完整五条，不拆成五次调用。已有内容默认保留；选择重写后只改勾选字段，显式填写的批量覆盖值优先。

SKU/属性和图片的开关位于对应功能页，均有预设规则与可编辑提示词。编码会加商品ID以降低重复风险，不替换已有编码。属性仅接受逐字出现于当前商品资料的证据；未知平台ID、无直接依据、认证、产地、危险品、品牌、尺寸重量、识别码、价格库存等不会由AI猜测。新增AI能力默认关闭；开启后运行确认会说明计费。

| Amazon：220114595361361938 | 8560商品标识码 + 13013型录错误 | 已整理描述并保存回读；需真实UPC/EAN/GTIN、获批豁免或型录状态确认 |

本轮对3件Amazon失败商品保存了可修部分并回读。3件的价格、库存、主图、类目和原识别码均保持一致；标题与item_name同步一致。保存修复草稿不会清除平台历史发布错误，**不等于已重新上架**。本轮没有执行线上发布。

新增「分析发布失败」「修复发布失败商品」入口：读取最新状态 → 分类 → 准备可确定修复 → 记录阻断项 → 根据所选去向保存或提交。默认保存修复结果；选择发布时有阻断项则停止该件。只审核不重发、相同修复不重复发送、未知保存结果不盲目重试；重试上限1至3次。

## 已修复的程序问题

- Amazon编辑标题与schema属性item_name不一致，导致平台持续报旧标题重复；现在两处同步，卖点和描述亦同步。
- 100521审核提示会盖住100470、90220、8560、13013等真正错误；现在实际错误优先。
- Amazon统一售价使用错误的后端字段名；现写入standard_price，并兼容旧price配置。
- Alibaba统一售价/阶梯价被原定价模型忽略；显式统一定价时写入相应定价模型，同时检查两种预设冲突。
- 产能范围2000-10000 pcs/day、深度2000-2600 mm和尺寸数字被误判为电话；修复识别，保留真实参数。
- 阿里巴巴关键词提示词编辑入口缺失；新增并与实际后台配置键一致。
- 搜索条件变化后仍留在旧页码；现在重置第一页，支持回车搜索。
- 慢搜索和慢商品详情请求可能覆盖后一次选择；增加请求序号检查，过时成功/失败结果均不覆盖当前状态。
- 非法批量JSON会导致功能页无法打开；现在保留原数据、显示修复输入，并阻止无效配置启动。
- 同一确认操作连点可能堆叠重复弹窗；相同确认不重复打开。取消普通商品加载成功toast，状态仍显示在页面与日志。
- 并发自动保存共用临时文件可能相互覆盖；配置保存串行化，内容未变且文件未被外部修改时跳过重复写盘。
- 自动处理每个事件都刷界面并重复写同一结果日志；保留完整落盘事件，合并高频绘制，去掉重复结果日志。
