# AuroraList 安装与首次使用（Windows）

## 一、新电脑要装什么？

| 项目 | 是否必须 | 说明 |
|---|---|---|
| Windows 10/11 64 位 | 必须 | 不支持 Win7/32 位 |
| Python | **不需要** | 安装包/便携包已内置 Python 与 Flet 运行时 |
| Chrome 或 Edge | **必须（二选一）** | Win10/11 自带 Edge 即可；Chrome 更稳。用于登录店小秘、读 Cookie、CDP 自动化 |
| ffmpeg | 可选 | 只有「主图视频」需要；不装不影响上架、AI 图片、价格等 |
| 网络 | 必须 | 需访问 `license.moneyfly.club`、`api.moneyfly.club`、`dianxiaomi.com` |
| 管理员权限 | 不需要 | 安装包默认装到当前用户目录（`%LOCALAPPDATA%\Programs\AuroraList`） |
| VC++ 运行库 | 通常不需要 | Win10/11 自带；极老系统若提示缺失，装微软 VC++ 2015-2022 x64 |

### 两种安装方式

1. **安装包（推荐）**：`AuroraList-Setup-1.2.0.exe`
   - 双击 → 下一步 → 自动创建开始菜单快捷方式（桌面快捷方式可选）
   - 卸载：设置 → 应用 → AuroraList → 卸载
2. **便携包**：`AuroraList-windows.zip`
   - 解压到任意目录（路径不要有中文/空格更稳），双击 `AuroraList.exe`
   - 换电脑直接复制整个文件夹

> 安装包/EXE 目前没有代码签名，Windows 可能弹「已保护你的电脑」：点「更多信息 → 仍要运行」。这是 SmartScreen 对未知发布者的提示，不是病毒。

## 二、装好就能直接用吗？

**程序本身可以启动，但业务上还需要 3 样东西，缺一不可：**

1. **授权（按机器绑定）**
   - 新电脑的机器码和旧电脑不同，**旧电脑的授权不能直接复制过来**。
   - 打开软件 → 设置 → 授权 → 复制机器码 → 发给管理员登记 → 点「重新检测」。
   - 已登记后显示「授权有效 / 到期时间」。
   - 老客户如果是从旧版客户端升级，且**同一台电脑**，可把旧软件的「设备授权 ID」填到「旧版授权 ID」继续用。
2. **API Key**
   - 设置 → API → 填 API Key → 「测试连接」。
   - 没有 Key：AI 标题/描述/SKU/图片全部不可用；上架本身也会因为缺内容失败。
   - 购买/充值按钮会跳转到你的 API 后台。
3. **店小秘登录态**
   - 店铺设置 → 「读取并同步」（读本机 Chrome/Edge 已登录的店小秘），或「粘贴 Cookie」，或「启动浏览器（兜底）」登录一次。
   - 没有 Cookie：读不到店铺/产品，无法上架。

另外建议首次设置：

4. 选择店铺 → 选择模板产品（选一次会保存，下次自动带出）
5. 高级设置 → 水印（可选）
6. 设置 → 并发数（默认 4；电脑差/网络慢调到 2）

## 三、首次使用步骤（照着点）

1. 启动软件，若弹首次设置向导：选浏览器 → 读取已登录的店小秘 → 选店铺/模板 → 完成
2. 设置 → 授权：复制机器码给管理员 → 登记后点「重新检测」
3. 设置 → API：填 Key → 测试连接
4. 店铺设置：读取并同步 → 确认店铺/产品数
5. 选择模板产品 → 等「模板参数已读取」→ 保存到本地（可选）
6. 概览 → 启动上架（先建议把「自动保存」关掉试跑）
7. 任务与日志：看进度/心跳；要停就点「停止任务」

## 四、可选：ffmpeg（主图视频）

不装也能用软件，只是「生成主图视频」会提示未找到 ffmpeg。

- 下载 Windows 版 ffmpeg（gyan.dev 或 BtbN builds），解压后把 `ffmpeg.exe` 放到：
  - `AuroraList.exe` 同目录，或
  - `AuroraList\_internal\assets\bin\ffmpeg.exe`，或
  - 把 `ffmpeg.exe` 所在目录加入系统 PATH
- 重启软件 → 图片工作台 → 生成视频，能预览即成功。

## 五、数据与卸载

- 配置/日志/缓存：`%APPDATA%\AuroraList\`
  - `config.json`（API Key、Cookie、模板、价格表等）
  - `error.log`（崩溃/UI 异常，反馈问题时发这个）
  - `cache\image_cache.json`（图片结果缓存）
  - `logs\`（如已开启）
- 多开：每个实例有独立配置目录（`%APPDATA%\AuroraListInstances\<实例名>`）和独立 CDP 端口
- 卸载安装包不会删除 `%APPDATA%\AuroraList`（保留授权/配置）；要彻底清空需手动删该目录

## 六、已知限制（重要）

- **定时发布需要软件保持运行**；关闭软件后不会执行。到点前请让软件开着（可最小化）。
- 授权离线宽限 72 小时；超过后需要能访问授权服务器。
- 主图视频依赖 ffmpeg；未安装时该功能不可用，其余功能正常。
- 店小秘页面改版可能导致自动化选择器失效；先点「打开店小秘」确认页面能正常打开，再反馈日志。
- 安装包未签名，SmartScreen 提示属正常。
- 更新：设置 → 版本更新 → 检查更新；服务器配置了 `downloadUrl` 才能一键下载安装。

## 七、故障排查

| 现象 | 处理 |
|---|---|
| 启动提示未授权 | 复制机器码给管理员登记；新电脑必须重新登记 |
| AI 全部失败 | 设置里 API Key 是否填、测试连接是否通过、余额是否足够 |
| 读不到店铺/产品 | 重新登录店小秘 → 重新检测 Cookie；或粘贴 Cookie；Chrome 正在运行导致 Cookie 库锁定时先关 Chrome |
| 启动浏览器失败 | 确认装了 Chrome/Edge；杀毒软件是否拦截远程调试端口 |
| 视频失败 | 未装 ffmpeg；按第四节放置 |
| 软件卡住/闪退 | 发 `%APPDATA%\AuroraList\error.log`；日志页看最后一条步骤 |
| 安装后图标/水印资源缺失 | 确认解压完整；不要只复制 exe，`_internal` 目录必须一起 |
