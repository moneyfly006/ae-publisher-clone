# Alibaba 平台 UI 复查与去重（2026-11-22）

目标：Alibaba 平台只保留一套清晰流程，去掉重复入口/重复控件，减少误会。

## 1. 页面结构（调整后）

| 页面 | 职责 |
|---|---|
| 概览 | 状态、准备检查、去刊登入口 |
| **Alibaba 连接** | 只负责 Cookie/店铺连接检测（不再有商品选择） |
| **Alibaba 刊登** | 商品 → 类目 → 预设资料 → 价格与贸易 → 保存与发布 |
| 发布队列 | 只读数量 + 「发布失败」原因 |
| AI 文案/图片/内容审查/任务日志/图片工作台/设置 | 平台通用工具 |

- 移除了 Alibaba 导航里重复的「类目与属性」页（类目信息已并入刊登页「类目」Tab）。
- 移除了 Alibaba 导航里单独的 Cookie/商品重复入口。

## 2. 已合并/删除的重复项

- 刊登页「连接与商品」Tab：删除重复连接卡（Cookie/店铺 ID 只在连接页维护）。
- 连接页删除重复的「校验商品 ID」「去 Alibaba 刊登」「查看发布队列」（导航已有）。
- 删除「AI 预演」「预演（不保存）」及旧 AI 保存卡，合并为**一个保存动作 + AI 开关**：
  - 保存按钮随 op 动态显示：保存草稿 / 移入待发布 / 提交审核·发布 / 定时发布。
- 删除第 3 页重复的 Alibaba 行业预设控件（统一在刊登页「保存与发布」套用）。
- 删除图片工作台 Alibaba 重复的 Cookie 连接卡（Alibaba 只处理 URL/本地图片）。

## 3. 容易误会的地方已修正

- 公司介绍/FAQ：现在真实写入 `companyDesc/companyFaqDesc`（op=1 实测接受并回读），
  标签明确「会提交」；公司名称/网站/贸易条款等仍标「本地」。
- 运费模板：从手填 ID 改为**下拉选择 + 读取模板**。
- 价格与贸易：按定价方式动态显示
  - 阶梯价 → 显示档位表
  - FOB → 显示币种/最低/最高价
  - 保留原价 → 显示说明，不再堆无关字段。
- 商品页增加「连接/Cookie 设置」快捷入口；连接页说明指向刊登页。
- 保存按钮文案与实际动作一致，避免「保存到 Alibaba」实际执行发布/定时。

## 4. 验证

- `tests/test_ui_alibaba_actions.py`：无预演入口、可视化编辑器、保存/AI 开关、发布失败列表。
- `tests/test_ui_redesign.py`：Alibaba 导航/页面/Tab 结构。
- 按钮审计：见 `docs/ui-button-audit.json`（0 ERROR）。
- 真实 op=1：companyDesc/companyFaqDesc 平台接受并回读。

## 5. 仍保留（非 Alibaba）

Amazon/TikTok 页面仍有各自平台的预演流程；如需一并删除，需另行确认。

## 6. 实际发布模式验证（2026-11-22）

- 用真实 App 对象（非沙箱、真实网络）在 Alibaba 刊登页点击：
  - 「保存草稿」→ 确认弹窗 → 真实写入，商品 `offline/waitPublish`；
  - 「提交审核 / 发布」→ 确认弹窗 → 商品 `online / publishSuccess`，`errMsg` 空。
- 因此 Alibaba 页面不是预演模式；四个按钮均真实写入店小秘/平台。
- 当前页面新增的四个显式动作：保存草稿 / 提交审核·发布 / 移入待发布 / 定时发布。
- 运费模板下拉会自动加载；未加载时显示占位选项，不再出现“空下拉无法选”。
- 移除了重复的「生成属性预设模板」入口（保留可视化属性预设编辑器 + AI 建议）。

## 7. 「运行」按钮提示修复（2026-11-22）

- Alibaba 平台点侧栏运行按钮（文案「去 Alibaba 刊登」）以前会闪一条**红色错误提示**：
  「Alibaba 商品请在「Alibaba 刊登」页选择并保存（批量管线仅用于速卖通）」。
- 现在改为正常跳转：绿色提示「已打开「Alibaba 刊登」页：请选择商品后保存/发布」，
  日志写 INFO，不再看起来像软件故障；按钮 tooltip 同步为「打开 Alibaba 刊登页」。
- 键盘 ⌘R/Ctrl+R 与 `_start()` 同样走该守卫，不再弹错误。
- 验证：`tests/test_ui_alibaba_actions.py::test_start_guard_redirects_alibaba_platform` 通过。

  `platform=alibaba` 的店铺（当前账号：9466975 zzyugong），选中即保存；
  顶栏店铺按钮显示当前 ICBU 店铺名。
- **推荐发布信息**：
  - 首次启动（Alibaba 配置为空）自动填入机械类推荐值；
  - `保存与发布` 页提供「填入推荐发布信息」按钮，可随时恢复。
  - 内容：类目 `127726092`（其他混凝土机械）、属性预设（Core Components/Warranty/
    Origin/Model/Weight/USP）、包装 `300X200X200`、重量 `500`、库存 `5`、
    运费模板 `2055583029`、HS `84791000`、发货期 `15` 天、起订量 `1`、

- 启动时若检测到 Alibaba 配置为空会一次性写入并保存，之后可在页面修改。

## 9. 用通俗语言 + 各平台独立 Cookie + 采集箱批量（2026-11-22）

- 去掉 UI 里的 “ICBU” 术语：改为「Alibaba 店铺」「Alibaba 连接」「Alibaba 草稿」等通俗中文。
- Cookie 分平台独立保存：
  - **Alibaba**：`Alibaba 连接` 页「Alibaba 专用 Cookie」；留空时沿用店小秘登录 Cookie；
  - **速卖通**：`店铺与登录` 页的店小秘 Cookie；
  - **Amazon**：Amazon 刊登页「店小秘 Cookie」→ `amazon_cookies`；
  - **TikTok**：TikTok 刊登页「店小秘 Cookie」→ `tiktok_cookies`。
- **采集箱批量处理**（参考速卖通，不需要手动选商品）：
  - Alibaba 刊登页「商品」Tab 自动读取采集箱（草稿）商品；
  - 提供「处理全部（保存草稿）」「处理全部（发布）」「刷新采集箱」；
  - 可设置本次处理数量与本次是否用 AI；逐条显示成功/失败原因；
  - 每个商品保留自己的类目，不会被全局预设类目改类目。
- 推荐发布信息：首次启动自动填入，或点「填入推荐发布信息」恢复。

## 10. 「选择商品后仍提示选择」与「类目自动识别」修复（2026-11-22）

- 之前保存/评分在未选商品时会提示「先选择一个商品」；现在：
  - 未选商品时自动读取**采集箱第一个商品**并继续执行，不再反复要求手选；
  - 仍可在商品列表点「选择」切换；
- 选择商品后自动识别类目：
  - 列表自带类目 → 自动写入并读取类目路径；
  - 列表没有类目 → 自动读商品详情 `categoryId/fullCid`，再读类目名称与必填属性；
  - 状态栏显示「已自动识别类目并读取必填属性」，不需要先去类目页手动搜索；
- 批量处理同样按每个商品自己的类目执行，不会统一改成预设类目。

## 11. 侧栏「处理采集箱」按钮（2026-11-22）

- 以前侧栏按钮写「去 Alibaba 刊登」，点击只是跳到 12 号页，不会处理任何商品，
  客户会认为“点了运行不工作”。
- 现在按钮文案改为 **「处理采集箱」**：
  1. 点击后打开 Alibaba 刊登页；
  2. 弹出确认「将处理采集箱前 N 个商品（保存草稿）」；
  3. 点「开始处理」才真正执行，逐条显示成功/跳过/失败；
  4. 批量进行中再次点击会提示“正在处理中”，不会重复启动。
- 验证：真实 App 对象点击侧栏按钮 → 出现确认框 → 开始处理 →
  `批量完成：成功 0 / 跳过 10 / 失败 0`（当前采集箱是泳池商品、目标类目是机械类，按设计跳过）。
