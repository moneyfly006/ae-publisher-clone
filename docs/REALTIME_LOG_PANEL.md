# 顶栏「实时日志」面板（2026-11-23）

## 修改
- 右上角原来的「查看任务与日志」图标按钮只做 `_switch(10)` 跳页；
- 现在改为 **「实时日志」** 按钮，点击直接展开弹窗，不离开当前页面；
- 所有平台共用同一个顶栏按钮，因此 Alibaba/速卖通/Amazon/TikTok/Shopee 都有；
- 弹窗：
  - 标题「运行日志（实时）」；
  - 级别筛选（全部/INFO/WARN/ERROR）；
  - 进度条 + 步骤/耗时/花费；
  - 日志列表 540px 高、1000px 宽，每 2 秒自动刷新、自动跟随最新；
  - 「清空 / 导出 / 打开完整任务与日志」按钮；
  - 关闭后停止刷新线程。
