## 布局与保留功能

12 个页面按商品准备、内容处理、发布与运行、工具与设置分组；原页面 ID 与配置键保留。发布队列默认先显示「运行与发布设置」，包含处理产品数量、编辑完成后去向和记录/失败重试；「商品队列」放在后面。视频来源、模板视频路径、轮播参数移到「AI 图片 → 商品视频」。商品与图片处理前后对比保留。
