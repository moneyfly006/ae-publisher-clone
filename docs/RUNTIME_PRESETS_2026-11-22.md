# 运行稳定性与参数预设

四个平台的「保存与发布 / 发布与结果」页增加运行参数卡片。参数已内置于程序默认配置，不必先手工填写；已有自定义值保留。速卖通使用原有流程，本轮预设仅作用于 Alibaba、Amazon、TikTok、Shopee。

| 预设 | 平台请求超时 | 只读重试 | 商品间隔 | 连续失败停止 |
|---|---:|---:|---:|---:|
| 稳健（默认） | 30 秒 | 2 次 | 1 秒 | 3 件 |
| 低频 | 60 秒 | 2 次 | 3 秒 | 3 件 |
| 快速 | 20 秒 | 1 次 | 0 秒 | 3 件 |

选择预设后点击「应用运行预设」，修改立即保存，下次任务生效。「调整运行参数」可单项修改。预设仅改变当前平台这四项，不修改处理数量、关键词、发布去向、价格库存、类目、公司资料或付费 AI 开关。当前运行任务使用确认时的配置快照。

默认处理前 10 件、保存草稿、已有资料保留、文案只补缺失。付费 AI 文案、图片、SKU、属性开关仍默认关闭；开启时需要有效 API Key。SKU / 属性提示词为空或只有空格时，自动使用内置规则，不改变用户原配置。

## 运行问题与修复

- 平台请求超时现在独立于 AI 模型超时。自动处理及失败修复使用同一份运行参数。
- 临时网络错误、超时、部分 HTTP 5xx / 限流，仅对白名单中的只读操作有限重试；最多为首次加配置的重试次数，避免叠加平台客户端自身重试。等待每 0.1 秒检查停止信号。
- 保存、发布和其他写方法不经过读取重试封装；网络异常不盲目重发。失败修复原有的有界、变更方案重提交流程继续保留，仅对明确的新失败状态生效。
- 登录失效停止后续商品。连续失败达到阈值停止；成功商品会重置连续失败计数。阈值 0 表示不限制，但登录失效仍停止。结果页与日志显示停止原因，保留已完成结果。
- 停止时不取消已提交商品的第一次结果回读；当前请求无法强制取消，要等待其请求超时。范围读取中的重试等待可正常停止且不开始写入。
- 拦截字符串 / 数字形式的异常开关，防止 `"false"` 被 Python 当成开启。超时、重试、间隔及阈值均检查类型、范围和有限数值。
- 修正 TikTok 批量属性默认结构为原生数组，并校验各平台批量属性、贸易和阶梯报价结构，拒绝布尔值冒充价格或库存。
- 付费 AI、自动图片和失败修复读取商品详情时验证 ID；采集箱服务中的所有详情读取也校验，空详情、错误类型或错误商品 ID 不再继续处理。
- 后台线程创建失败或进入任务页失败时恢复空闲状态；即使日志刷新线程也无法创建，仍保留文件日志和启动失败提示。
