# 授权中心兼容改造任务

约束：旧授权库、设备授权 ID、状态、期限及签名密钥不变；旧验证接口及日志接口地址保留。套餐账号继续使用原账号和原订单，不合并或删除历史授权。

- [ ] 备份代码、两套 SQLite 一致快照及签名密钥，记录旧授权逐行校验摘要。
- [ ] 建立共用有效权益计算：按平台/功能各自到期，追加开通不丢失已有平台；兼容旧版 Token。
- [ ] 统一套餐设备绑定、软件登录、授权刷新；保留旧设备验证路径，补齐套餐设备的原软件验证兼容。
- [ ] 整理后台分组，用户详情集中展示有效权益、历史授权、设备、订单和日志入口。
- [ ] 增加套餐用户日志筛选、详情与用户端日志；关联确切设备 ID，防止串用户，保留旧日志入口。
- [ ] 修复用户端授权页异常、状态刷新及移动端溢出，保留购买、订单、发票、工单等现有入口。
- [ ] 修复订单重复履约和自动续费重复扣款，统一业务服务与定时任务依赖。
- [ ] 禁止公开下载数据/备份；使用一致 SQLite 备份；不改变原授权数据库路径。
- [ ] 隔离兼容测试：旧授权通过/过期/吊销、原日志、套餐多平台/不同期限/多设备/重复付款/续费。
- [ ] 本地 PHP 构建检查及浏览器桌面/手机验收，部署后比较旧授权摘要、验证新旧接口与日志页面。

界面结构：客户与授权（套餐用户、账号平台权限、原设备授权）；运行与日志（客户日志、设备运行、操作审计）；交易与套餐（套餐、订单、退款、发票、工单）；系统管理（管理员、支付、系统、安全）。
