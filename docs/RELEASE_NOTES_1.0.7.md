# AuroraList v1.0.7 发行说明（2026-11-23）

修复线上日志反馈的速卖通 SKU 问题：

- 采集数据 `aeopSKUProperty` 中的元数据（skuImage/extraImages/imageUrlList 等）、
  `None/空串/list/dict` 值在解析前统一清洗，不再误报
  「SKU 一致性检查失败：属性键和值必须是非空标量」。
- 标准形态缺少有效 `propertyValueId` 的单个属性会被剔除，保留其余真实规格；
- 清洗后完全重复的 SKU 组合由恢复流程自动合并（保留第一条、库存累加）；
- 同一份清洗结果同时用于保存/身份匹配，减少「处理后的 SKU 无法匹配原商品」。
- 后台日志反馈的 1.0.5 机器应升级到 1.0.7 后重试。

验证：
- `tests/test_sku_clean.py` 新增，覆盖元数据/空值/清洗后重复；
- 离线全量 1268 测试通过。
