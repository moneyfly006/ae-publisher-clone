# 全面核查与修复（2026-11-23）

## 已修复的真实问题

1. **新装默认开启了付费 AI/图片，导致无 API Key 时所有平台预检失败**
   - 修复：安装包 preset 不再导出 `*_collect_ai` / `*_collect_images`；默认关闭。

2. **个人 Amazon/TikTok 站点被导出为安装默认值**
   - 影响：Amazon 商品站点校验把其他站点商品判为“另一站点”，失败商品无法恢复。
   - 修复：`export_preset` 排除 `_site/_site_code/_site_name`；preset 默认清空。

3. **图片序号为空时没有被预检拦截**
   - 修复：`collect_preflight` 对空 `image_indices` 判定无效，必须填写 1~N。

4. **TikTok/站点自动初始化导致批量设置被误判“店铺或站点已切换”**
   - 修复：设置字段只比较店铺/站点/模式，允许页面初始化自动带出；不再因 Cookie 轮换失效。

5. **店铺预设同步在 Cookie 轮换/自动带出站点时重置刚保存的批量设置**
   - 修复：scope 在店铺/站点绑定时不再纳入 Cookie；仅在真实店铺切换/已保存预设时重置。

6. **损坏批量预设修复被“预设已改变”误拦截**
   - 修复：修复确认阶段允许页面初始化自动带出站点；其他真实变化仍拦截。

7. **SKU 模板补 plug 覆盖型号导致重复（上一轮）**
   - 已修复并有回归测试。
