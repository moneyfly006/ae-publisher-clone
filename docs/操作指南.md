# AuroraList 操作指南

> 本软件把一个「采集箱」里的速卖通草稿商品，用 AI 自动优化标题/详情/SKU/图片后，
> 通过店小秘接口**直接保存或发布**（不走浏览器模拟，速度快、可并发）。
> 本文解释每个页面、每个按钮、每个设置项的作用。

---

## 一、快速开始（3 步）

1. **店铺设置** → 自动读取本机 Chrome/Edge 已登录的 Cookie（读不到就粘贴一次）→ 选店铺
2. **基础设置** → 选「模板商品」（必填：模板的属性/品牌/说明书等会补齐到新商品）
3. **概览** → 确认「真实写入」→ 点「启动」

保存后，商品去向由「发布到什么地方」决定：
- **待发布**（save_only）= 只保存，留在待发布
- **直接发布**（publish）= 保存并发布上线

## 三、店铺设置（第 1 步）

| 项 | 作用 |
|---|---|
| 读取 Cookie | 自动从本机 Chrome/Edge 读已登录的店小秘；读不到点「粘贴 Cookie」贴一次即可 |
| 店铺 | 选择要上架的店铺 |
| 模板商品 | **必填**。选一个同类目的已完善商品，它的品牌/产地/说明书/运费服务模板等会自动补齐到新商品 |

> 模板商品是本软件的核心：新商品缺失的所有系统属性、说明书、海关监管、运费/服务模板，
> 都从模板的 `edit.json` 合并进来。**没有模板就无法保存。**

## 四、基础设置（原「属性设置」）

### 规格与库存
- 重量/长/宽/高：默认包装规格（**填了就按这个，不填才用采集值**）
- 货值默认值：申报货值（速卖通草稿必填）
- 优先使用采集重量尺寸：用采集到的重量/尺寸（克自动换算 kg）
- 启用自定义 SKU 前缀 / 库存改为 999 / 自动生成 SKU 编码 / 是否原箱

### 类目属性默认值（模板读不到时用）
- 高关注化学品 / 是否带电：默认「否」

### 详情本地图（新增）
- 「选择图片」从电脑选 png/jpg
- 选插入位置：开头 / 结尾 / 头尾都插
- 刊登时自动上传图床并写进商品详情

### 额外选项（原「设置」页里的，已并入这里）
| 开关 | 作用 |
|---|---|
| 四合一主图 | 把 4 张图**本地**拼成一张（不调 AI，免费） |
| 启用主图作为详情图 | 主图拼进详情 |
| 主图不足 6 张用额外图片补齐 | 补满 6 张 |
| 保留主图及 AI 生成图到本地 | 存一份到本地 |
| 添加自定义详情文本/图片 | 详情头部/尾部加文字 |
| 复制 SKU 至详情 | SKU 名称列表追加到详情 |
| 违禁词检查 | 标题/详情过违禁词库 |
| 使用模板产品视频 / 生成主图轮播视频 | 视频来源（见第八节） |
| 保存时清理与系统属性重名的自定义属性 | **自动删除重复属性**（品牌/型号/产地等，通用检测） |
| AI 出图直传店小秘图片空间 | 不用图床，直接传店小秘 |
| 刊登后自动清理相册 | 删 N 天前未被引用的图 |
| 发布到什么地方 | 待发布 / 直接发布 |

## 五、AI 设置

### 标题
- 启用 AI 标题 + 标题提示词 + 前缀/后缀
### 详情
- 启用 AI 详情 + 详情提示词
### SKU
- 启用 AI 优化 SKU + SKU 提示词
### 读图估重
- 启用 AI 估重：根据标题和主图估算毛重/尺寸，填入规格

> 这些提示词**已预写在每个功能上**，直接决定 AI 产出质量，改动立即用于下次刊登。

## 六、AI 图片设置

| 功能 | 走 API？ | 说明 |
|---|---|---|
| 白底 | ✅ API | 把商品图背景换成纯白 |
| 去水印 | ✅ API | 去除水印 |
| 翻译 | ✅ API | 图上文字翻译 |
| 精细化编辑 | ✅ API | 按提示词改指定图 |
| 四合一主图 | ❌ 本地 | PIL 本地拼图，免费 |
| 营销图 | ✅ API | 生成 1:1 + 3:4 两张，写进营销图片 |
| 主图视频 | ✅ 本地ffmpeg+API上传 | 见第八节 |

图片方案分两种：
- **通用编辑**：一条提示词按范围逐张改主图
- **精细化编辑**：指定第 N 张 + 单独提示词

所有 AI 图片产出都要 ≥800×800（`img_min_size_enable`），不合格的自动保留原图。

## 七、价格 / 变种

### 阶梯倍率（内部计价）
按成本落在哪一档用该档倍率（成本 × 倍率 + 固定加价），只影响你算出的售价。

### 区域调价（店小秘同款，会写入平台）
- 打开「启用区域调价」
- 「添加国家」→ 选国家（US/RU/BR…）+ 填**绝对价**（元）
- 刊登时写入 `aeopNationalQuoteConfiguration`，美国买家看到的价与国内不同

### 批发（店小秘同款，会写入平台）
- 打开「启用批发」
- 填「购买 N 件以上」「减免 X%」「一件代发折扣 Y%」
- 刊登时写入 `bulkOrder` / `bulkDiscount`

> 实测已确认：保存后从店小秘回读，`bulkOrder=2`、`bulkDiscount=15`、
> `aeopNationalQuoteConfiguration` 都在，**真的生效**。

## 八、视频（三种来源）

| 来源 | 现状 |
|---|---|
| 采集视频 | 商品自带视频（edit.json 的 videoUrl） |
| 模板视频 | `使用模板产品视频` 开关 |
| 生成轮播视频 | `生成主图轮播视频` 开关 |

> 视频：勾「使用模板产品视频」（填本地 mp4 路径）或「生成主图轮播视频」（自动用主图合成），
> 保存时会本地合成 → 上传店小秘 → 写入 `cspVideoId`。失败不影响保存。

## 九、运行与发布

- 概览页「运行模式」：**试跑**（只算价格/计划，不调 AI 不保存）vs **真实写入**
- 「启动」：并发处理（并发数 = 设置里的 `concurrency`，1-8）
- **无需打开浏览器**：保存/发布/读模板全部走 API
- 「停止」：中断正在处理的图片、停心跳

## 十、设置页（API / 图床 / 模型）

- API Key：AI 服务的密钥（测试连接）
- 图床地址/密钥：AI 出图转存到你的图床
- 保留天数：图床清理 N 天前的图
- 模型：选 AI 图片模型（默认 qwen-image-3.0）

## 十一、概览页的三张智能卡片

| 卡片 | 作用 |
|---|---|
| **成本 / 用量** | 今日花费、近 7 天花费、按功能拆分的调用次数与金额 |
| **断点续传** | 上次批量中断后显示「剩余 N 个 / 失败 M 个」，点「继续处理剩余」只跑没做的 |
| **改前后对比** | 最近处理商品的标题/详情/主图改前 vs 改后 |

## 十二、常见问题

| 现象 | 原因 | 解决 |
|---|---|---|
| 「API 直存不可用」 | 没选模板商品 | 基础设置选模板 |
| 「保存失败！某属性不能为空」 | 模板缺该属性 | 换模板或用类目属性默认值 |
| 商品在审核中被跳过 | 商品在线/审核中 | 等审核过，或换草稿商品 |
| 图片 <800 被拒绝 | 生成图太小 | 换模型或提示词要求高清 |
| 主图不足 6 张不补 | 未开「补齐」开关 | 基础设置里打开 |

---

## 十三、一句话总结

**读 Cookie → 选店铺 → 选模板 → 配 AI 提示词 → 启动**，剩下的（属性合并、图片处理、保存/发布）全自动。
