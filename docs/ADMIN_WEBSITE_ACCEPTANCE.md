# 网站管理员后台验收记录

本轮修改网站管理员后台及授权、日志接收服务，已部署到 https://license.moneyfly.club/admin 。软件客户端和速卖通流程未在本轮修改。

## 页面与设置

后台按问题分析、客户与授权、日志与设备、交易与服务、系统管理组织。表单统一为桌面双列、手机单列；输入、下拉与按钮统一 40px，多行文本默认 112px。移除重复外框和叠加样式，套餐列表与编辑分开。

系统设置采用一个入口、十个用途分区：授权默认值、日志与保留、日志识别效果、支付网关、邮件与验证、用户端设置、接口访问、登录密码、两步验证、平台与接口。原设置地址仍可访问；各分区独立提交，后端白名单约束可写字段，完整校验后事务保存。修复取消勾选后无法关闭开关的问题；空接口密钥保留原值，更换需明确操作；保存日志规则与清理日志分离。

按用户最新要求删除退款管理、发票页面、管理路由、处理函数、用户端发票入口与 API。生产对应模板文件已移除。历史业务表不删除；历史退款订单状态及支付回调保护保留，避免将旧订单重新履约。静态退款政策作为法律说明保留。

## 授权与排障

保留原设备授权码及全部操作，套餐账号采用独立权益聚合，不重写历史授权。客户详情关联账号、设备、平台权限、订单与运行日志。日志保留原上传入口和原文查看，新增事件去重、来源标记、问题归类和处理备注；草稿、审核中、明确发布结果分别统计。平台能力由注册表及版本化接口提供，新增平台可扩展。

## 套餐用户日志搜索与诊断追加验收

已上线 `/admin/customer-logs`：按邮箱、姓名、用户编号搜索并分页，精确邮箱/编号优先展示；选择用户后按文件、软件版本、设备及错误筛选日志。文件名和“详情与诊断”均可打开详情，返回时保留用户、两类搜索、错误开关和分页条件。

详情顶部展示问题类别、优先级、带行号的日志证据、可能原因、解决步骤、验证方法；支持证书、请求限流、额度、类目权限、会话授权、程序异常、属性、标识品牌、图片、物流价格、AI 输出及网络问题，未知问题明确待核实。429 同时包含明确额度不足时优先归为额度问题。历史错误不因后续成功记录被抹去；草稿和提交成功仍需核对平台结果。分析最近 8000 行并显示范围，展示正文和证据再次脱敏，不调用外部 AI，不修改客户配置或商品。

本地通过 19 项 HTTP、34 项诊断、6 项浏览器操作及 92 次全后台桌面/手机检查；服务器 PHP 7.4 通过相同 34 项诊断测试，43 页渲染无错误。生产实际账号邮箱/编号搜索通过；20 份真实历史设备日志可正常分析。当前生产套餐账号暂无已关联日志，详情点击链路使用隔离账号验证，没有将其他客户日志强行归属给它。设备绑定/核实关联及上传后，授权范围内日志会显示。
