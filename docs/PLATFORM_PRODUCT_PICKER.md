# 各平台商品选择器（对齐速卖通）

## 需求
其他平台（Alibaba/Amazon/TikTok/Shopee）的自动处理运行页也要支持：
- 搜索标题/商品 ID；
- 分页；
- 全选本页 / 全选筛选结果；
- 运行只处理勾选的商品。

## 实现
- 新增通用 `product_picker()`：
  - 数据源：采集箱 / 待发布 / 发布失败；
  - 本地标题/ID 搜索；
  - 每页 50 条，上一页/下一页；
  - 全选本页、全选筛选结果、清空选择；
  - 勾选结果写入 `{platform}_collect_selected_ids`。
- 运行页新增「选择商品」「清空选择」和已选数量提示。
- `run_collect` 在读取范围后按 selected_ids 过滤，未选择时保持原行为（全部符合条件商品）。
- 配置默认新增 `*_collect_selected_ids = "[]"`。

## 说明
- 商品读取由各平台现有客户端完成；不同平台支持的状态以接口返回为准。
- 选择范围只影响本次自动处理，不修改商品本身。

## 范围优先级修复
- 已选商品 ID 优先于关键词与“本次处理数量”：运行时会先读全量源数据，再只保留勾选 ID；
- 不在当前店铺/站点/数据源中的已选 ID 会记录“已跳过”提醒；
- 新增 `tests/test_selected_scope.py` 验证“已选 ID 覆盖关键词和数量限制”；
- 四平台选择器打开测试已加入 `tests/test_platform_picker.py`。
