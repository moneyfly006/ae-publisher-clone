# 处理规则页面 - 详细设计

> **设计目标**: 将分散在多个页面的设置统一到一个页面，让用户一次性配置所有处理规则

**页面路由**: 所有平台的 Page 44 (Alibaba) / Page 45 (Amazon) / Page 46 (TikTok) / Page 47 (Shopee)  
**页面标题**: "处理规则"  
**设计版本**: v2.0 (2026-11-24)

## 🎨 交互行为

### 1. 折叠面板
- 默认展开"商品基础设置"和"AI 自动处理"
- "高级选项"默认折叠
- 用户可点击标题切换展开/折叠状态
- 折叠状态保存到本地（下次打开时恢复）

### 2. 实时验证
- 价格输入框只允许数字和小数点
- 类目选择后自动验证是否在店铺经营范围内
- JSON 编辑器实时高亮语法错误
- 提示词长度超过 2000 字符时警告

### 3. 智能推荐
- 首次进入时，根据店铺历史商品推荐类目
- 根据商品类型推荐提示词预设
- 价格计算规则根据平台推荐（Alibaba 推荐 FOB，Amazon 推荐自动计算）

### 4. 预设管理
- 点击"提示词预设"下拉框显示 15+ 行业预设
- 选择预设后自动填充所有提示词字段
- 可保存自定义预设（"存为我的预设"按钮）

### 5. 规则导入导出
- 导出为 JSON 文件（包含所有配置）
- 导入时自动验证兼容性
- 支持从其他平台导入（自动转换字段名）

### 页面加载逻辑

```python
def build_rules_page(app, platform: str):
    """构建处理规则页面"""
    # 1. 从配置加载当前规则
    rules = load_platform_rules(app.cfg, platform)
    
    # 2. 构建表单
    controls = []
    
    # 商品基础设置卡片
    basic_card = build_basic_settings_card(app, platform, rules)
    controls.append(basic_card)
    
    # AI 自动处理卡片
    ai_card = build_ai_settings_card(app, platform, rules)
    controls.append(ai_card)
    
    # 预算控制卡片
    budget_card = build_budget_control_card(app, platform, rules)
    controls.append(budget_card)
    
    # 高级选项卡片（默认折叠）
    advanced_card = build_advanced_options_card(app, platform, rules)
    controls.append(advanced_card)
    
    # 底部操作按钮
    action_bar = build_action_bar(app, platform, rules)
    controls.append(action_bar)
    
    return ft.Column(controls, spacing=16, scroll=ft.ScrollMode.AUTO)
```

### 保存逻辑

```python
def save_rules(app, platform: str, rules: ProcessingRules):
    """保存处理规则到配置"""
    # 1. 验证规则
    errors = validate_rules(rules, platform)
    if errors:
        app.show_error("配置验证失败", "\n".join(errors))
        return False
    
    # 2. 转换为配置字典
    config_dict = rules_to_config(rules, platform)
    
    # 3. 合并到全局配置
    for key, value in config_dict.items():
        app.cfg.set(key, value)
    
    # 4. 保存到磁盘
    try:
        save_config(app.cfg)
        app.toast("处理规则已保存")
        return True
    except Exception as e:
        app.show_error("保存失败", str(e))
        return False
```

## 💡 实现注意事项

### 1. 性能优化
- 使用虚拟滚动（`ft.ListView` 替代 `ft.Column`）
- 折叠面板内容懒加载（展开时才创建控件）
- 防抖动保存（500ms 内多次修改只保存一次）

### 2. 用户体验
- 保存成功后显示 Toast 提示
- 配置修改后页面标题显示"未保存"标记
- 离开页面前检查是否有未保存的修改
- 首次使用显示引导提示

### 3. 兼容性
- 兼容旧版配置（自动迁移）
- 导入时检查平台兼容性
- 字段缺失时使用默认值

### 4. 可维护性
- 每个卡片独立成一个函数
- 配置字段使用 dataclass（类型安全）
- 单元测试覆盖核心逻辑
