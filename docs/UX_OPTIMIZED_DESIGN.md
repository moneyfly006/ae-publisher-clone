# AuroraList 用户体验优化设计

> 从用户实际操作流程出发，重新设计 UI 和功能布局

**设计理念**: 
1. **渐进式引导** - 新手能在 5 分钟内完成第一次刊登
2. **配置一次、重复使用** - 规则设置后自动应用到所有后续任务
3. **智能默认值** - 95% 的用户不需要改配置就能用
4. **费用透明** - 每一步都显示会花多少钱
5. **容错设计** - 失败后能快速定位问题并重试

---

## 🎯 核心问题分析

### 当前用户痛点（通过代码分析）

1. **配置项太多**（136+ 项）
   - 用户不知道哪些必填、哪些可选
   - 缺少"快速开始"模式

2. **费用不透明**
   - 代码里有 `api_balance` 但 UI 没有实时显示
   - 用户不知道一次任务会花多少钱

3. **失败后难以重试**
   - `publish_retry.py` 存在但 UI 入口不明显
   - 失败商品需要手动一个一个处理

4. **平台切换混乱**
   - 每个平台页面结构不同
   - 切换平台后找不到对应功能

5. **启动按钮含义不清**
   - `btn_run` 在不同平台显示不同文案
   - 用户不确定点了会发生什么

```python
def estimate_cost(products: list, config: dict) -> dict:
    """实时费用估算"""
    text_cost = 0
    image_cost = 0
    
    for product in products:
        # 文案费用
        if config.get("enable_ai_title"):
            text_cost += 0.03
        if config.get("enable_ai_detail"):
            text_cost += 0.03
        
        # 图片费用
        image_count = len(product.get("images", []))
        if config.get("enable_main_white_bg"):
            image_cost += 0.02
        if config.get("enable_detail_remove_watermark"):
            image_cost += image_count * 0.02
    
    return {
        "text_cost": text_cost,
        "image_cost": image_cost,
        "total": text_cost + image_cost,
        "time_estimate": len(products) * 20,  # 秒
    }
```

```python
def preflight_check(products: list, config: dict) -> list:
    """处理前预检"""
    warnings = []
    
    for product in products:
        # 检查类目
        if not product.get("category_id"):
            warnings.append({
                "product_id": product["id"],
                "type": "warning",
                "message": "商品未设置类目，可能导致发布失败",
            })
        
        # 检查必填属性
        if not product.get("attributes"):
            warnings.append({
                "product_id": product["id"],
                "type": "warning",
                "message": "商品缺少必填属性，建议开启 AI 自动补全",
            })
    
    return warnings
```
