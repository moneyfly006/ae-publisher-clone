## 6. 主流程（截图之外的逻辑，来自 67 模块规格）

1. 打开浏览器 → 连接店小秘 → 取采集箱/待发布列表
2. 逐产品：属性 → 变种映射 → SKU 优化 → 标题/详情 AI 生成 → 图片流水线（白底/去水印/编辑/背景）→ 价格计算 → 上传图片 → 发布
3. 失败按阈值熔断，日志实时输出，结束后统计成功/失败/跳过

## 7. 对重构版的启示

- 老软件是「单页多标签」结构，配置项密集、说明文字多 → 新版本改为**左侧导航 + 分组卡片 + 折叠面板**，降低认知负担
- AI 提示词全部可配置 → 新版本保留「提示词库」模块
- 价格/变种是专业功能 → 新版本用**向导式表单 + 实时预览**
- 图片流水线最重 → 新版本做**独立工作台 + 任务队列**
