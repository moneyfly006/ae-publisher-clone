# 店小秘商品描述图片核验

核对了工作区中保存的店小秘编辑页 DOM、页面加载的 JavaScript 和字段序列化逻辑。范围为普通商品刊登及编辑。Amazon Seller Central 帮助链接返回登录页。本次没有提交商品或执行线上发布。

| 平台 | 编辑页和脚本证据 | AuroraList 处理 |
| --- | --- | --- |
| Amazon | 普通描述用 CKEditor。DOM 中的工具栏提供粗体、斜体、列表及标记源码。图片操作位于独立的「产品图片」模块。脚本将描述映射到 `product_description.0.value`，图片使用 `main_product_image_locator`、`other_product_image_locator_*` 等字段。描述路径中共享的 HTML 整理函数也能读到 `IMG` 标签，单凭这条代码无法证明刊登支持描述插图。 | 单品和批量图片编辑只提供主图与附图。普通描述保存前检查嵌入媒体，文字排版兼容店小秘使用的 HTML。旧版保存的 Amazon 描述图片规则在读取时跳过，同行的商品图规则继续生效。 |
| TikTok | 描述区 DOM 显示「展开图片栏」「问题图片检测」及描述图片计数。脚本配置 `imagePanelToggle` 和 `img[!*]`，从编辑器读取图片并随 `description` 回写。页面显示通常最多 30 张，限额字段为 `descImgMax`。 | 按描述图片分组处理，只写回 `description` 中对应的图片。保存校验读取站点限额。 |
| Alibaba 国际站 | 描述页包含独立的「详情图片」区域。新版描述脚本把卖点文字放入 `textDesc`，把图片分类、URL 和配文序列化到 `detailImage`。脚本另外区分公司描述图片 `companyImage`。 | 商品详情图片走 `detailImage`。商品描述和公司描述分别使用自己的字段。 |
| Shopee | 采样页面的普通描述使用 `product-desc-textarea`。脚本通过店铺状态判断 `isDescWhiteList`，通用保存函数按该开关写入普通 `description` 或 `descriptionType=extended` 和 `descriptionInfoStr`。新版描述校验使用 `descImageNumMax`，全球站点限额样本为 12 张。 | 普通描述使用文字。已读取为新版描述的商品开放详情图，保存时按站点限额检查。 |
