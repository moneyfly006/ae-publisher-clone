# 概览「开始一次任务 / 选择商品 / 搜索全部商品」修复（2026-11-23）

## 确认的问题
- 「选择商品」只读采集箱前 500 条，无分页，只按标题过滤，不能按商品 ID 搜。
- 「搜索全部商品」每个状态只读前 300 条，无分页；ID 搜索失败。
- 运行时即使勾选商品，只在前 500 条采集箱里找 ID，选中商品在后面的页/其他状态会找不到。

## 修复
- 两个商品选择弹窗都支持：
  - 分页（每页 50 条，上一页/下一页/第 N/M 页）；
  - 标题搜索；
  - 商品 ID 精确搜索；
  - 「全选本页」。
- 「搜索全部商品」增加「全部」状态，可跨采集箱/待发布/发布失败/在线/审核中去重展示（当前店铺 1100 条）。
- 运行范围改为 `products_by_ids`：按勾选 ID 跨状态查找，不再依赖前 500 条；找不到/不可处理的 ID 会写日志。
- 行为确认：
  - 勾选了商品 → 只处理这些商品；
  - 不勾选 → 按原逻辑处理全部可编辑商品（仍受处理数量限制）。
