**常见错误及解决**:
```
❌ AI 标题: Invalid token
   → 配置API Token

❌ 简单处理·主图: 成功 0 / 失败 X
   → API Token问题或图片URL无效

❌ 异常: Cannot switch to a different thread
   → 线程隔离失败 (应该已修复)

❌ PRODUCT_IN_AUDIT_PENDING
   → 商品在审核中，跳过

❌ 保存失败: 必填项缺失
   → 商品信息不完整
```
